# Source and storage

This generic cloud entrypoint was authored for the uploaded portable job-application skill. The complete uploaded package and its original business rules are retained in private cloud runtime storage, without modifying the original skill files.

The package contains personal career information, application history, source materials and Windows-encrypted credentials. Neither those assets nor identifying manifests are distributed through this public repository. The original fonts and documents retain their original rights and notices in private storage.

The cloud entrypoint delegates to the privately installed package. It does not claim that Windows DPAPI works on Linux or that job-site accounts are authenticated. It performs no application submission during installation.
